KEEPING YOUR CHARACTERS BETWEEN VERSIONS
=========================================
Characters, gear and settings are stored by your BROWSER, not in the game folder. Some browsers (Firefox
especially) only show them to the exact folder the game was opened from, so a new version unzipped into a
different folder can look empty. They are not deleted - they are still in the old place.

Easiest, always works (30 seconds):
 1. In the OLD version: Settings -> Data -> Save backup (saves a chalice-backup-DATE.json to Downloads).
 2. Open the NEW version, Settings -> Data -> Restore from a backup, pick that file. Characters come back.

To avoid it entirely:
 - Unzip each new version INTO THE SAME FOLDER as the old one (overwrite files) and open it the same way
   (same browser, same shortcut).
 - Do not open index.html from inside the zip.
Settings -> Data shows where your characters are saved right now.
